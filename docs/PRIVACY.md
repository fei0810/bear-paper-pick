# 隐私与本地配置

Jev 接收公开题名、DOI、年份、刊名、英文摘要及切句，以及研究画像的正向轴、负向轴、逻辑形和语言。研究方向本身可能敏感，首次启用时明确说明；已有同范围授权可用于继续运行。`screen --plan-only` 无需 key，只在本地写出完整请求预览。

PDF、全文、私人笔记、原始用户反馈、线名、种子列表、候选发现通道和本地路径不进入 Jev 请求。英文标记来自数据源，不为了补齐数量而猜测。完整资格与判断约束见 [Jev 策略](../references/jev-policy.md)。

密钥由进程环境变量、`BEAR_PAPER_PICK_ENV_FILE` 指向的文件或安装目录 `.env` 提供。旧 `BEAR_SIFT_ENV_FILE` 继续作为回退。文件路径按显式 `--env-file`、新环境变量、旧环境变量、安装目录 `.env` 的顺序选择；具体字段仍以进程环境变量为优先。文件不进 Git、安装包和运行记录。源码更新不改写用户配置。

本地 plan、screening 和审计记录含研究画像，仍应按用户研究资料管理。发布问题报告时提取最小复现，避免公开整个运行目录。服务方当前的数据处理条款需在实际使用时核对，不宣称默认零留存或没有研究信息外发。
